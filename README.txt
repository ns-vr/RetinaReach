RETINAREACH POLISHED PROTOTYPE

Run locally:
1. Extract this folder.
2. Open index.html in a modern browser (Chrome, Edge, Firefox, Safari).
3. Use fictional participant codes only.

Includes a premium UI polish pass, responsive styling, scroll reveals, a reading progress indicator, basic image-quality heuristics, local browser records, and CSV export.

Limitations: this is a frontend prototype. Authentication is local/demo only. Image quality checks are unvalidated browser-side heuristics. No diabetic-retinopathy inference model is connected. Do not use for diagnosis or real patient-care decisions. Local browser data is not a secure medical record system.
